# Issue and Root-Cause Records

Use [`../templates/ISSUE-RCA-TEMPLATE.md`](../templates/ISSUE-RCA-TEMPLATE.md) for defects, security findings, performance problems and compatibility failures.

## Severity

- `P0` — data loss, security breach or complete outage
- `P1` — severe operational impairment
- `P2` — important defect with workaround
- `P3` — minor defect or usability issue
- `Enhancement` — capability request
